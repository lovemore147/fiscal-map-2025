# 2025年全国城市财政自给率地图

交互式地图覆盖337个地级行政区及直辖市，其中329个已核实、8个待核实。数据核验截至2026年10月9日。

财政自给率 = 2025年全市（全州、地区、盟）一般公共预算收入 ÷ 一般公共预算支出。金额单位为亿元。点击地图或选择地区可查看收支、比率、官方来源及口径说明。待核实地区标为灰色，不作为零值处理。

## 发布

将本目录的 `index.html` 和 `.nojekyll` 放入 GitHub 仓库的 `main` 分支根目录。在 Settings → Pages 中选择 Deploy from a branch，发布分支选择 `main`，目录选择 `/ (root)`。

网页是独立静态页面，无需构建或后台服务。绘图库与地理数据已内嵌，无需登录即可查看。浏览器需支持 DecompressionStream。

## 数据与边界

- 每个地区的财政数据来源和核验状态均可在地图中查看。
- 边界来自 [DataV.GeoAtlas](https://datav.aliyun.com/portal/school/atlas/area_selector)，经简化用于统计展示。
- 伊犁采用全州口径，包含单列的塔城、阿勒泰，不能重复汇总。
- 统计范围不含县级市及港澳台。
- 绘图使用 [D3.js 7.9.0](https://d3js.org/)。
